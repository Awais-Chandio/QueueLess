# 1A.2 Memberships: org_members

## Goal
Clinic roles per organization (`owner | receptionist | doctor`), with one helper every policy and RPC can use.
`is_admin()` stays the **platform** admin (the QueueLess operator) and gives no clinic role.

## What the migration adds
- **`org_members (organization_id, user_id, role)`**: PK on all three (a person can be owner *and* doctor),
  FKs cascade on organization or account delete, index on `user_id`. RLS on.
- **`private.has_org_role(org_id uuid, roles text[])`**: true when the caller holds one of `roles` in
  `org_id` **and the organization is `active`** (suspending a clinic stops all its clinic roles at once).
  NULL org → false.
- **Backfill** from the legacy tables:
  | Source | Membership |
  |---|---|
  | `staff_centers` row whose profile has `role = 'staff'` | receptionist of that center's organization |
  | `doctors.profile_id` (account exists) | doctor of that doctor's center's organization |
  | `profiles.role = 'admin'` **with** `profiles.center_id` | owner of that center's organization |
- **Sync triggers**, so the admin app keeps working without code changes:
  - `staff_centers` insert/update/delete adds or removes the receptionist row (removed only when no other center of
    that organization is left for the person).
  - `doctors` insert / update of `profile_id`/`center_id` / delete does the same for doctor rows.
  - `profiles.role` leaving `staff` drops receptionist rows; becoming `staff` restores them from `staff_centers`.
- **Access**: members read their own rows, owners read their organization's roster, platform admins read
  all. Organizations: members read their own. **No client write grants** on `org_members`.

## Decisions (safest option)
- **Platform admins without a center get no membership.** Making them owner of every default organization
  would be a tenant-level grant that survives a later demotion. Their access stays `is_admin()`. Default
  organizations therefore have **no owner** until one is assigned (manual step, see the Phase 1A summary).
- **Receptionist requires `profiles.role = 'staff'`**, exactly like today's `is_staff()` gate, so no one gains
  access in the backfill. `staff_centers` rows of non-staff profiles grant nothing.
- **Doctors need no profile role**: same as today (`is_doctor_self` only checked `doctors.profile_id`).
- Triggers are created before the backfill (no window for missed rows).
